CMOS Bandgap Reference (BGR) Design and Layout using SKY130 PDK

This project focuses on the design and layout of a CMOS Bandgap Reference circuit using the SKY130 130-nm CMOS process. The design combines PTAT and CTAT voltage components to achieve temperature-compensated reference voltage generation.
The project involves CMOS analog circuit design, gm/ID-based transistor sizing, a five-transistor OTA, a voltage-output stage, and a startup topology. Xschem is used for schematic design, ngspice for circuit simulation, and KLayout for custom IC layout.
Technologies: SKY130 PDK, Xschem, ngspice, KLayout, CMOS Analog Design, gm/ID Methodology.
